# ชุดเก็บหลักฐานจากผู้ใช้จริง

สถานะวันที่ 30 ตุลาคม 2026: เจ้าของโครงงานแจ้งว่ายังไม่มีผลสัมภาษณ์หรือการทดลอง เอกสารนี้เป็นแบบเก็บข้อมูล ไม่ใช่ผลการศึกษา และห้ามนำช่องว่างไปนับว่าเสร็จแล้ว

## วิธีดำเนินการ

คัดเลือกผู้ดูแลจากบ้านที่มีผู้ดูแลสัตว์อย่างน้อย2คน ตั้งเป้าเริ่มต้น5บ้าน บันทึกวิธีคัดเลือก ช่วงวันเก็บ จำนวนบ้าน/คน และข้อจำกัดตัวอย่าง ไม่รวมเพื่อนที่เพียงเปิดเว็บดูโดยไม่ได้เลี้ยงร่วมกันเป็นหลักฐานผู้ใช้เป้าหมาย

อ่านให้ผู้เข้าร่วมทราบ: “เราขอสอบถามวิธีแบ่งหน้าที่ดูแลสัตว์และให้ลองระบบเพื่อทำโครงงานรายวิชา การร่วมเป็นไปโดยสมัครใจ หยุดได้ทุกเมื่อ ไม่ขอรหัสผ่าน ที่อยู่ หรือข้อมูลการรักษา ใช้รหัสแทนชื่อ และนำเสนอผลรวมที่ไม่ระบุตัวบุคคล” บันทึกความยินยอมและการอนุญาตใช้คำพูด/ภาพแยกกัน เก็บต้นฉบับในพื้นที่ส่วนตัว `research-private/` ที่ Git ignore

## แบบทดสอบการใช้งาน

ใช้ข้อมูลสังเคราะห์ ให้ผู้ทดลองทำเอง ผู้สังเกตไม่ชี้นำจนกว่าจะขอความช่วยเหลือ แยกข้อผิดพลาดของระบบออกจากความไม่เข้าใจ UI

|---|---|---|---|---|---|

## แบบบันทึก baseline และ trial

เก็บ7วันก่อนใช้และ7วันทดลองในบ้านเดิม หากทำไม่ได้ให้รายงานจำนวนวันจริงและไม่อ้างว่าครบ14วัน บันทึกแต่ละรายการด้วยรหัสบ้าน/วันที่/ชนิดงาน/due/เวลาเสร็จ/ผู้บันทึกเป็นรหัส/หลักฐานที่ได้รับอนุญาต/ข้อสังเกต เลี่ยงชื่อสัตว์จริงในข้อมูลที่จะเผยแพร่

นิยามงานเลยเวลา = ไม่มีเวลาเสร็จภายใน due; ตัวหารคืองานที่ถึงกำหนดทั้งหมดในช่วง ไม่รวมงานในอนาคต บันทึกข้อมูลหายแยกต่างหาก อัตราลดลงสัมพัทธ์ = (อัตรา baseline − อัตรา trial) / อัตรา baseline ×100 ถ้า baseline=0 ให้รายงานอัตราทั้งคู่และส่วนต่างเป็นจุดเปอร์เซ็นต์ ไม่หารด้วย0 เป้าหมาย20%เป็นเป้าทดลอง ไม่ใช่ผลที่เกิดแล้ว
