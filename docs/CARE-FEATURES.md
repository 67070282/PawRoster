# PawRoster 2.1 — สมุดบันทึก ปฏิทิน และการจัดการสัตว์เลี้ยง

## ลบหรือเก็บประวัติ

รุ่นก่อนมีเฉพาะ “เก็บประวัติ” ซึ่งหยุดการสร้างงานใหม่ แต่ยังแสดงการ์ดอยู่ รุ่นนี้แยกมุมมองเป็น กำลังดูแล / เก็บประวัติ / ถังขยะ / ใช้งานและเก็บประวัติ

| การกระทำ | ผล |
|---|---|
| เก็บประวัติ | เก็บข้อมูลไว้โดยหยุดสร้างงานใหม่ ต้องไม่มีงานค้างก่อน |
| ลบสัตว์เลี้ยง | พิมพ์ชื่อยืนยันแล้วซ่อนจากรายการปกติ ย้ายไปถังขยะและยกเลิกงานค้างใน Transaction เดียว ประวัติเดิมและสมุดบันทึกยังอยู่ |
| ลบถาวร | เจ้าของบ้านเลือกในถังขยะและพิมพ์ชื่อยืนยัน ลบข้อมูลสัตว์เลี้ยง งานดูแล ประวัติ สมุดบันทึก และนัดหมายทั้งหมดของตัวนั้นใน Transaction เดียว กู้คืนผ่านหน้าเว็บไม่ได้ |
| กู้คืน | กลับมาดูแลและเห็นสมุดบันทึกเดิมได้ งานที่ยกเลิกตอนลบจะไม่เปิดกลับอัตโนมัติ |

เจ้าของบ้านเป็นผู้เก็บประวัติ ลบ และกู้คืน สมาชิกทั่วไปเพิ่มและแก้ไขข้อมูลได้ โดยหน้าสัตว์เลี้ยงระบุสิทธิ์ของผู้ใช้ปัจจุบัน ถังขยะไม่มีวันหมดอายุและไม่มีการลบอัตโนมัติ เลือกกู้คืนหรือลบถาวรได้ การลบถาวรตรวจสถานะถังขยะล่าสุดเพื่อป้องกันการยืนยันจากหน้าจอเก่า ข้อมูลสำรองที่ผู้ดูแลเคยสร้างไว้อยู่นอกขอบเขตคำสั่งนี้

## ข้อมูลสัตว์เลี้ยง

เพิ่มสายพันธุ์ เพศ และวันเกิดแบบไม่บังคับ พร้อมข้อควรทราบเดิม วันเกิดตรวจว่าเป็นวันที่จริงและไม่อยู่ในอนาคต

## สมุดบันทึก

- ประเภท: น้ำหนัก (กิโลกรัม), วัคซีน, พบสัตวแพทย์ และบันทึกทั่วไป
- ระบุหัวข้อ วันที่/เวลา หมายเหตุ และนัดครั้งถัดไปสำหรับวัคซีนหรือพบสัตวแพทย์
- เลือกสัตว์เลี้ยงเพื่อดูน้ำหนักล่าสุด ความต่างจากครั้งก่อน และ 6 บันทึกล่าสุด
- ค้นหา กรองตามประเภท/สัตว์เลี้ยง และส่งออกข้อมูลที่กรองเป็น CSV ได้ โดยป้องกันข้อความที่ขึ้นต้นแบบสูตร Spreadsheet
- ผู้สร้างบันทึกหรือเจ้าของบ้านแก้ไขและลบบันทึกได้ การลบบันทึกแต่ละรายการเป็นการลบถาวรและมีหน้าต่างยืนยันแยกจากการลบสัตว์เลี้ยง
- นัดหมายทำเครื่องหมายเสร็จ/เปิดกลับได้ เมื่อแก้วันนัดใหม่ สถานะนัดเดิมจะถูกรีเซ็ต

ข้อมูลเป็นการบันทึกจากผู้ดูแล ไม่มีการวินิจฉัย แนะนำยา หรือคำนวณตารางวัคซีนอัตโนมัติ

## ปฏิทินงานและนัดหมาย

แสดงรายเดือนตามเวลาท้องถิ่นของอุปกรณ์ รวมงานดูแลที่สร้างแล้วและนัดหมายจากสมุดบันทึก เลือกวันเพื่อดูรายการ กรองสัตว์เลี้ยง/สถานะ เลื่อนเดือน กลับวันนี้ หรือสร้างงานในวันที่เลือกได้ งานซ้ำแสดงเฉพาะรายการที่สร้างจริง ครั้งถัดไปเกิดหลัง Complete ไม่มี Push/email notification

## มอบหมายงาน

เจ้าของบ้านมอบหมายงานที่ยังเป็น open ให้สมาชิกปัจจุบันของบ้านได้ ผู้รับเห็นงานใน “งานที่ฉันรับ” และมีสิทธิ์คืน/ยืนยันเสร็จตามกติกาเดิม บันทึก Audit ระบุผู้มอบหมายและชื่อผู้รับ

## การอัปเกรด

สำรองฐานข้อมูลตาม [OPERATIONS.md](OPERATIONS.md) ก่อนเริ่มรุ่นใหม่ รุ่นนี้อัปเกรด schema 2 → 3 แบบ Atomic โดยเพิ่มฟิลด์ pets, events.detail และตาราง pet_records บัญชี Session งาน ประวัติ และ Membership เดิมยังอยู่ การย้อนกลับใช้ไฟล์สำรองก่อน Migration ไม่ให้โค้ดรุ่นเก่ามาเขียนฐานข้อมูลใหม่

การเพิ่มลบถาวรตรวจด้วย C8–C9 ครอบคลุมสิทธิ์ เจ้าของบ้าน/สมาชิก/ต่างบ้าน การยืนยันชื่อและสถานะล่าสุด การลบข้อมูลที่เกี่ยวข้อง การคงข้อมูลสัตว์ตัวอื่น Persistence และ Rollback เมื่อเกิดข้อผิดพลาด รวมชุดปัจจุบัน 26 กรณี (27 TAP records รวม Parent) หลักฐานรุ่น 2.1 ด้านบนเป็นผลก่อนเพิ่มฟีเจอร์นี้
