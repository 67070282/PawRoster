# PawRoster 2.0 — หลายบ้านและการดูแลที่ต่อเนื่อง

## ปัญหาที่ปรับปรุง

รุ่นเดิมผูกบัญชีกับบ้านหลังเดียว และรับรหัสเชิญได้เฉพาะตอนสมัคร จึงไม่รองรับผู้ดูแลที่มีบัญชีอยู่แล้วและต้องช่วยดูแลสัตว์เลี้ยงในบ้านอื่น รุ่น 2.0 เปลี่ยนเป็นความสัมพันธ์หลายบ้านผ่าน memberships โดยยังคงระบบรับงานและประวัติเดิม

## ฟีเจอร์

| ส่วน | พฤติกรรม |
|---|---|
| หลายบ้าน | สร้างบ้านเพิ่ม เข้าร่วมด้วยรหัสหลังสมัคร และสลับบ้านได้ในบัญชีเดียว |
| สิทธิ์ | แต่ละบ้านมีเจ้าของหนึ่งคนและสมาชิกหลายคน สิทธิ์แยกตามบ้าน |
| จัดการบ้าน | เจ้าของบ้านเปลี่ยนชื่อ เปลี่ยนรหัสเชิญ นำสมาชิกออก และโอนสิทธิ์ได้ |
| ออกจากบ้าน | สมาชิกออกเองได้ งานที่รับค้างกลับไปรอผู้รับผิดชอบ และประวัติยังอยู่ |
| ข้อมูลสัตว์เลี้ยง | แก้ชื่อ ประเภท ข้อควรทราบ เจ้าของบ้านเก็บประวัติ/นำกลับมาใช้งานได้เมื่อไม่มีงานค้าง |
| งานดูแล | ความสำคัญปกติ/สำคัญ การแก้ไขก่อนมีผู้รับ และการยกเลิกโดยผู้สร้างหรือเจ้าของบ้าน |
| งานซ้ำ | เลือกรายวัน/รายสัปดาห์ Complete ครั้งปัจจุบันแล้วสร้างครั้งถัดไปใน Transaction เดียว |
| ค้นหาและกรอง | ชื่องาน สัตว์เลี้ยง ผู้รับผิดชอบ หมายเหตุ งานของฉัน งานวันนี้ เลยกำหนด และสถานะ |
| หน้าจอ | แยกตารางดูแล สัตว์เลี้ยง บ้านและสมาชิก ประวัติ รองรับจอมือถือ |
| การอัปเดต | โหลดข้อมูลทุก 30 วินาทีเมื่อมองเห็นหน้าและไม่มี Dialog เปิด พร้อมปุ่มอัปเดตเอง |

## สิทธิ์และข้อจำกัด

- ทุกคนในบ้านสร้างสัตว์เลี้ยงและงานได้ ผู้รับงานเท่านั้นที่คืนงานและยืนยันว่าทำแล้ว
- ผู้สร้างงานหรือเจ้าของบ้านแก้ไขรายละเอียดได้เมื่องานยังเป็น open; ยกเลิกได้เมื่องานยังไม่เสร็จ
- การนำสมาชิกออกไม่ลบประวัติ และไม่ทำให้รหัสเชิญเดิมหมดอายุ เจ้าของบ้านเปลี่ยนรหัสได้เพื่อจำกัดการกลับเข้าร่วม
- เจ้าของบ้านโอนสิทธิ์ให้สมาชิกคนอื่นก่อนออกจากบ้าน ไม่มีการลบบ้านหรือบัญชีในรุ่นนี้
- สมาชิกเห็นเฉพาะชื่อและบทบาทของคนในบ้าน ไม่ได้รับอีเมลสมาชิกอื่นหรือรหัสเชิญหากไม่ใช่เจ้าของบ้าน
- บ้านที่เลือกแยกตาม Session; แท็บที่ใช้ Cookie เดียวกันใช้ Session ร่วมกัน UI ส่ง X-Home-ID ป้องกันคำขอจากหน้าบ้านเก่าเขียนผิดบ้าน
- งานซ้ำสร้างเมื่อยืนยัน Complete โดยเพิ่มจากกำหนดเดิม 24 ชั่วโมงหรือ 7 วัน หากงานเดิมล่าช้า งานถัดไปอาจเลยกำหนดเช่นกัน ไม่ใช่ระบบ Scheduler หรือการแจ้งเตือน

## อัปเกรดข้อมูลจากรุ่น 1.0

สำรองฐานข้อมูลด้วย Online backup ก่อนเริ่มรุ่นใหม่:

```sh
node scripts/backup.mjs backups/before-v2.db
```

หากใช้ Docker กับรุ่นเดิม:

```sh
docker compose exec -T app node scripts/backup.mjs /tmp/before-v2.db
docker compose cp app:/tmp/before-v2.db ./before-v2.db
```

เก็บไฟล์สำรองในพื้นที่ส่วนตัว เมื่อเริ่มรุ่น 2.0 โปรแกรมจะ Migration ไป schema version 2 แบบ Atomic โดยเก็บบัญชี Session สัตว์เลี้ยง งาน และประวัติ ผู้ใช้ที่สมัครก่อนที่สุดในแต่ละบ้านเดิมจะเป็นเจ้าของบ้าน และสามารถโอนสิทธิ์ภายหลังได้ การเปิดแอปอีกครั้งไม่สร้าง Membership ที่ออกไปแล้วกลับมาใหม่

การอัปเกรด Docker ใช้ Compose project และ Volume เดิม:

```sh
docker compose up -d --build --wait
```

ฐานข้อมูล schema 2 ใช้กับโค้ดรุ่น 2.0 การย้อนกลับไปใช้รุ่น 1.0 ต้องหยุดบริการและกู้คืนไฟล์สำรองก่อน Migration ลงในสภาพแวดล้อมแยก ไม่สลับโค้ดรุ่นเก่ามาเขียนฐานข้อมูลใหม่โดยตรง

## การออกแบบหน้าจอ

ใช้สกิล [Ilm-Alan/frontend-design](https://github.com/Ilm-Alan/frontend-design) ในรุ่น 2.0 ภายใต้แนว Organic: โทนเซจ #8B9D83, ทราย #E8DCC7, ข้าวโอ๊ต #D4B895 และมอส #606C38 ใช้ฟอนต์ Epilogue แบบ Local พร้อม fallback ภาษาไทย การ์ดขอบมน 16–32 px และพื้นผิว Grain บาง ๆ ภาพวาดแมว/สุนัขในแถบบ้านและภาพประจำประเภทสัตว์เลี้ยงเชื่อมธีมกับการดูแล ตัวเลขสรุปเชื่อมกับงานที่กรองได้ ไม่มีตัวเลขตัวอย่างฝังในหน้าจอจริง
